**ZipImage 📸📦**

**Fonctionnalités**

*Scan intelligent* : Identifie instantanément toutes les images valides (protocoles HTTP/HTTPS) présentes sur la page.

*Sélection granulaire* : Choisissez précisément les images à inclure dans votre archive.

*Moteur optimisé* : Utilise un système de téléchargement par lots (batch processing) pour garantir la stabilité du navigateur, même avec des centaines d'images.

*Interface Bilingue* : Basculez entre le Français et l'Anglais en un clic.

*Format ZIP* : Compression automatique de toutes les images sélectionnées.

**Technologies utilisées**

*JavaScript (ES6+)* : Logique de l'extension et manipulation du DOM.

*Chrome Extension API* : scripting, downloads, storage, tabs.

*JSZip* : Bibliothèque pour la création de l'archive ZIP côté client.

*CSS3* : Design moderne et responsive avec support du mode "light".

**Installation (Mode développeur)**

Téléchargez ou clonez ce dépôt sur votre ordinateur.

Ouvrez votre navigateur (Chrome ou Brave) et accédez à chrome://extensions/.

Activez le Mode développeur via l'interrupteur en haut à droite.

Cliquez sur Charger l'extension décompressée (Load unpacked).

Sélectionnez le dossier contenant les fichiers de l'extension.

**💡 Conseil d'utilisation**

Pour une expérience optimale (téléchargement silencieux), désactivez l'option "Toujours demander où enregistrer les fichiers" dans les paramètres de votre navigateur.
